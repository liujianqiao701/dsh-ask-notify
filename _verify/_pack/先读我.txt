dsh-ask-notify 排查包
=====================

【先解压】不要在压缩包预览里直接双击：那样报告文件会落在临时目录，发不回来。
        解压成一个文件夹，里面几个文件必须放在一起，不要单独拷出去。

--------------------------------------------------------------------------
第一步：重启（先做这个，约 30 秒）
--------------------------------------------------------------------------
双击    重启并验证.cmd

  · 它会：停掉当前 DSH → 重新启动 → 等端口真的起来 → 自动打开浏览器
  · 新开的窗口标题是 "DSH web - do not close"，那是 DSH 本体，别关它
  · 跑完照窗口里写的做（这一步才算验证）：
        a) 浏览器按  Ctrl+F5
        b) 按 F12，点「Console / 控制台」标签
        c) 手敲这一行（不要粘贴），回车：
              __dshAskNotify
           · 显示一个可展开的对象 = 插件挂上了，继续 d)
           · 显示 undefined       = 没挂上，跳到第二步。
                                   （若你装的是 1.0.3 或更早，请先升级到 1.0.4 再试：
                                     老版本只认旧的等待态来源，会"静默不生效"）
        d) 手敲这一行，回车：
              __dshAskNotify.sources()
           · used: "uiSession.status" / "uiSession.pending" / "list"
             或 discovered:[...] 里列出的名字      = 取数源正常
             （pending: 0 只表示当前没有等待）
           · used: "none"   = 已知来源和自动探测都读不到（此时控制台会有一行警告、
                              右下角还会弹一张提示卡），看第二步
        e) 手敲这一行，回车（渲染自检，不依赖真的有等待）：
              __dshAskNotify.selftest()
           右下角弹出演示卡片并保持 12 秒   = 成功

  端口不是 3080 时：  重启并验证.cmd 3081
  平时启动带参数时：  重启并验证.cmd 3080 --host 0.0.0.0

--------------------------------------------------------------------------
第二步：只有第一步没成功才需要
--------------------------------------------------------------------------
双击    check-ask-notify.cmd

  · 只读诊断，不改动任何东西，约 3 秒跑完
  · 跑完会自动弹出资源管理器并选中报告文件
  · 把 dsh-ask-notify-report.txt 发回给作者
    （直接发这个文件，不要截图，也不要复制粘贴——粘贴会掉字符）

  端口不是 3080 时：  check-ask-notify.cmd -Port 3081

--------------------------------------------------------------------------
说明
--------------------------------------------------------------------------
重启并验证.cmd          会停/起 DSH。只处理占着那个端口的 node 进程，
                        杀之前会先确认它确实是 node.exe，别的程序不受影响。
check-ask-notify.cmd    启动器（必须和 .ps1 放在同一目录）
check-ask-notify.ps1    诊断本体，只读：查磁盘、找端口、读市场日志与 harness 版本，
                        并判断等待态数据源属于哪一代（0.1.7+ / 0.1.2-0.1.6 / ≤0.1.1）

如果双击后窗口一闪而过，说明被系统策略拦了：
右键这两个 .cmd → 属性 → 勾选“解除锁定” → 确定，再双击。
